## 🚀 Featured Projects

### 🍔 [Crave — Online Food Ordering](https://github.com/nguyenvinhz/Servlet_Project_Crave)

A team project covering the food ordering journey,
from browsing the menu to checkout and store management.

- Email OTP verification, account management, and staff permissions.
- Customizable menu items, shopping cart, and discount codes.
- QR payments through payOS and map-based delivery location selection.
- Transactional order processing and automated build/deployment workflows.

**Stack:** Java 17 · Servlet · JSP/JSTL · JPA/Hibernate · MySQL · Maven · AWS EC2

### 🧠 [Smart Sweeper](https://github.com/nguyenvinhz/smart-sweeper)

A visual application for exploring AI algorithms through Minesweeper.

- Implements 12 algorithms across six AI algorithm groups.
- Supports step-by-step playback and adjustable solving speed.
- Compares algorithms on the same board using execution metrics.

**Stack:** Python · Pygame · Search Algorithms · CSP

### 🏆 [VNOI Roadmap](https://github.com/nguyenvinhz/vnoi-roadmap)

A competitive programming learning roadmap with individual user progress.

- Account authentication through Supabase.
- Saves completed topics for each user.
- Uses database Row Level Security to separate user data.

**Stack:** React · Vite · Supabase · Vercel

[🌐 View Live Demo](https://vnoi-roadmap.vercel.app)

### 🧩 [AI Algorithms — 8-Puzzle](https://github.com/nguyenvinhz/AI)

A collection of AI exercises organized by algorithm family.

- Uninformed and informed search: BFS, DFS, UCS, A*, and more.
- Local search, belief-state search, and constraint satisfaction.
- Game search exercises including Minimax and Alpha-Beta pruning.

**Stack:** Python · Artificial Intelligence · Algorithms
